# Rust File Organizer

A CLI file organizer written in Rust that sorts files into categorized directories based on their file extensions.

## Project Status

In progress

## Planned Features

- Organize files by extension
- Create category directories automatically
- Move files into their corresponding categories
- Handle invalid paths and filesystem errors
- Command-line directory argument

## Concepts to Practice

- Ownership and borrowing
- Structs and enums
- Pattern matching
- `Option` and `Result`
- Iterators
- File system operations
- Error handling
- Modules
